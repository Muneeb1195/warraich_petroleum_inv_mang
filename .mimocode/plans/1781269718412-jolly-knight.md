# Plan: Fix Android Google Sign-In issues

## Issue 1: Account picker shows on first startup
The `GoogleSignIn` object in `backup_service.dart` is `late final`, but `google_sign_in_all_platforms` on Android may auto-trigger the credential manager when constructed. Fix: defer GoogleSignIn creation until `signIn()` is called.

## Issue 2: Sign-in fails silently — UI never updates
The `signIn()` method calls `_googleSignIn.signIn()` which returns null on Android (doesn't work like desktop). The switch stays off because `_credentials` is null. The `signIn()` returns false, and the `catch` block swallows the error.

Root cause: `google_sign_in_all_platforms` on Android may not support `signIn()` directly — it may need a different approach (e.g., `authenticate()` instead).

Fix:
1. Check if `signIn()` is the right method for Android, or if we need `authenticate()` or credential manager
2. Add error logging to see what's actually happening
3. If signIn returns null, show error to user
