# Google OAuth Secret Rotation — Step by Step

## No code changes needed — manual process only

1. Go to https://console.cloud.google.com/
2. APIs & Services → Credentials
3. Click + CREATE CREDENTIALS → OAuth client ID → Desktop app → Create
4. Copy new Client ID and Client Secret
5. Delete old OAuth client
6. Update GitHub Secrets: GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET
7. Update local lib/config/app_config.dart with new values
8. Test: sign in via Google on desktop app
